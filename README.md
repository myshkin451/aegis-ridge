# Project Aegis Ridge（磐石山脊高山生态与气象观测站 ARS-01）

一个以**现实工程可行性验证与双语域沉浸展示**为核心的 **交互式 3D 高山避难所数字孪生（Interactive 3D Shelter Digital Twin）**。

项目选址于海拔 `1,450.000 m` 的花岗岩南向半山腰平台：
- **山外是实景**：真实尺度的高山侵蚀山脊、远景群峰、物理天空与山谷云海，地表建有常规现代化高山科研观测站（L1–L2），周界与生命线严格遵循**“藏于科研”**原则（19 处外围设施全部拥有合理的高山科研或山地工程明面用途）。
- **剖开是图纸**：地表之下经由 `6.0 m` 复合防护层（钢筋混凝土顶盖 + 连续花岗岩）延伸出 4 层高规格地下自持综合体（B1–B4，单层 `32m × 24m = 768 m²`，地下合计 `3,072 m²`，全站总建面 `3,996 m²`），服务于一支 10 人规模、主副职互补的高素质专家团队。剖面与平面使用建筑和地质图例，近距管道以色环、介质名和箭头标识。

## 本地运行与校验

```bash
npm ci
npm run dev       # 生成地形并启动本地开发预览
npm run verify    # 执行 typecheck、Vitest 与生产构建
npm run shots     # 截取固定机位与专题实拍图（如 npm run shots -- wave1）
npm run perf      # 用 Chrome / ANGLE Metal 实测视图、步行、推近、透镜、管网拾取、M4/M5 工况与相机中心
```

在右上角切换现场、剖面、平面、X 光和漫游。“机位与图幅”里可以进入剖切盒、楼层俯瞰和场址总览，也可定位 19 处外围设施或重现五张签收图。按 `1` 现场、`2` 剖面、`3` 平面、`4` X 光、`5` 漫游。`[` 上一层，`]` 下一层。`V` 循环六个视角，`X` 切换 X 光，`O` 播放 75 秒开场序列，`H` 隐藏图签，`?` 查看键位。

- **看剖面与平面**　拖动剖面下方的 Z 滑杆切过核心筒。点标高尺选层，进入平面后拖红色游标可改变相对楼面的剖切高度。`M` 切换机电夹层。平面中点房间可查面积、净高与分区，按 `F` 聚焦选中的房间。
- **在三维空间移动**　在现场、剖切盒、楼层俯瞰和 X 光透视视角，拖鼠标环绕，滚轮推近。用 `W/A/S/D` 沿视向在水平方向飞行，`Q` 下降，`E` 上升，按住 `Shift` 加速；移动后自动沿屏幕中心视线无跳变重锚旋转中心。贴近地面时速度约 6 m/s，高空可达 70 m/s。现场镜头受地表和站房外墙约束。转场中可以拖动、滚轮或按键立即接管。
- **沿管网读图**　左下角图例可单独开关六套系统，`M` 控制夹层。选“X 光夜景”看全站，点蓝色给水或紫色排水段可追踪经过它的水路，悬停阀门可查看下游房间。漫游中按住 `Alt` 可局部透视，双击锁定指针后透镜位于屏幕中心。在地下走廊抬头超过 30° 可看吊顶后的管线。B2 也可从“机位与图幅”单独收起吊顶与灯槽。
- **走进建筑**　从“机位与图幅 → 房间索引”选房，或在图纸视图点房间、在三维视图点设备。右侧表可查位号、净用电的输入与输出、散热、尺寸和质量。选室内机位，再点“进入漫游”或按 `5`。现场进入地下房间会经过车库和货梯井，楼层俯瞰从上方落地。单击地面行走，拖动画面转头，也可用 WASD、Shift 或触屏摇杆。靠近气闸后长按 `E` 或屏上压差表约 1.5 秒。按一次 `Esc` 拉回俯瞰，再按一次返回现场。
- **读工程体检**　在左上图签选择日常、极寒、生化孢子或核尘埃。打开右上“工程体检”，将入住人数从 10 拖至 14。点一行可查看用量、单位和责任设备，并让镜头定位。表底“进入 B2 中控室”可以在实体控制台上读取同一次计算。
- **模拟检修与封锁**　在“模拟隔离检修”中选择设备位号或管段，再执行隔离。红线标出隔离部分，绿色标出求解到的备用支路，紫色虚线显示搬运路线。点“查看全程搬运”可从 B1 仓库沿货梯追到目标楼层，再点“返回检修位置”查看局部。生化孢子和核尘埃会启动 30 秒封锁。工程面板提供快进、重播和重置。
- **专家团、24 小时节律与照片模式**　打开右侧【专家团】可查看 10 位专家的主副职互助映射与负责房间/管网，点击【晨间巡检】启动第一人称自动导览（任意输入立即接管）。底部时间轴支持 24h 拖动与延时播放，联动太阳轨迹、B2 节律色温、夜间琥珀夜灯、中控室红光暗适应与 B3 错峰补光；支持 WebAudio 分层声景与照片模式（景深、移轴校正、16:9 / 4:5 / 2.39:1 取景框与 16 帧超分 PNG 导出）。网址附加 `?veg=v2` 可对照旧版植被。
- **复现画廊**　截图使用 Playwright Chromium 或本机 Google Chrome。首次安装浏览器可运行 `npx playwright install chromium`，也可设置 `CHROME_PATH` 指向现有 Chromium 可执行文件。运行 `npm run verify` 后执行 `npm run shots -- wave1`，查看[Wave 1 固定机位与实拍图](./docs/shots/wave1/)。[M2.5c 三间样板的四档对照图](./docs/shots/m2.5c/pilot/comparison.webp)

在“机位与图幅 → 固定摄影机位”选择“单人卧室 1”“光纤下的共餐客厅”或“卫浴镜柜与瓷砖”，分别在 19:30、10:30 和 19:30 进入 B2。网址加 `?quality=2&pilot=r1` 打开程序化材质与陈设，`r2` 换上实拍橡木、亚麻、墙面和瓷砖，`r3` 再加入软装、洁具、灯具、绿植、餐椅和科考挂画。默认使用 r3。同一菜单内的“公卫洁具近看”可同时看到洗手盆与马桶。原始 r0 来自 `ebbe617` 的封存截图。三个当前档位共用机位、时刻、曝光和画幅。[资产来源与尺寸](./public/assets/MANIFEST.md)

全站房间索引收录 27 间房。看平面时可从货梯南侧主走廊向东找到 2 米宽的北向联络廊，物流、图书馆、食品加工和地热各自在这一侧开门。B2 公卫从主走廊进入，淋浴、洗衣从居住内廊西端进入。居住区南排六个单人间、北排两个双人间，共十个常住床位。玄关旁的备勤宿舍另有四床。东侧前室把主走廊、居住区第二出口和疏散平硐接在一起。

地形由固定种子在构建期生成。`npm run terrain` 可单独重建测区与五个驱动通道。工程坐标见 `src/geometry/coords.ts`，外围设施见 `src/data/siteFacilities.ts`，摄影机位及其时刻见 `src/data/photographs.ts`。

## 开发推进方式（面向 Codex）

本项目采用 **Spec-Driven + 垂直里程碑分 Session + 5 机位截图人工签收** 模式推进：
1. 每个里程碑新开一个 Codex Session，发一句启动指令让其按 `AGENTS.md` 与 `docs/PROGRESS.md` 完成当前 `NEXT` 里程碑。
2. Codex 跑通 `npm run verify`（及 `M1.5b` 起的 `npm run shots` 5 机位截图）后，更新 `docs/PROGRESS.md` 标为 `REVIEW` 并提交推送。
3. 开发者在浏览器与验收画廊中确认满意后，签收为 `DONE` 并推进下一里程碑。
