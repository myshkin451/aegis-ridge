# 02. 视觉审美、程序化 3D 与交互规格（Visual & UX Spec）

> **核心诉求**：画质不需要走 3A 写实贴图路线，但用纯代码程序化生成的 3D 必须**耐看、精致、有高级建筑模型和硬核工程数字孪生的美感**，彻底摆脱“低幼塑料方块感”。

---

## 1. 视觉风格圣经：建筑微缩沙盘 × 洁净数字孪生

### 1.1 设计原则
1. **克制底色 + 精准高光**：山体、混凝土结构、深炭钢架保持低饱和哑光中性色；把高饱和与自发光完全留给 **6 大工程管网、指示灯、水培补光灯、情景灯光**。平时像一块精致的建筑竞赛实体模型，开启管网透视后瞬间呈现高信息密度的硬核工程剖面美感。
2. **结构先于装饰**：每个楼层都必须清晰看见**结构柱网、楼板厚度、顶棚机电夹层空腔、外围防渗沟和工字钢梁**。有了建筑骨架，哪怕内部设备几何体简洁，整体也会立刻显得真实可信。
3. **无“裸盒”铁律**：任何主要设备至少由 **3–5 个基础几何体组合而成**（底座减震垫 + 主箱体 + 倒角/肋板/管道接口 + 散热格栅或观察窗 + 微小状态灯），绝不允许一个单色 `BoxGeometry` 冒充反应堆或服务器。

## 2. 场景构成与程序化 3D 细节清单

### 2.1 半山腰等高线地形（Stepped Architectural Terrain）
- 山体不采用粗糙随机噪点泥块，而是采用**建筑沙盘式等高线阶梯地形（Terraced Contour Mesh）**叠加光滑坡面轮廓：
  - 坡面自北向南（`-Z` → `+Z`）自然倾斜，L1/L2 科研站优雅嵌在半山腰平台上，一条硬化山路盘至 L1 重载车库前坪；
  - 地下 B1–B4 完整埋藏于山体岩层内部，**正面（南侧/东侧）支持平滑剖切**：用户可选择：
    1. **完整山体模式（Exterior）**：欣赏半山腰科研站正常外观与山坡树林/积雪。
    2. **地质半剖面模式（Cutaway）**：切开山体南侧岩壁，一眼看清“6m 防护岩层 + 地下四层结构 + 贯通竖井 + 西侧平硐”。
    3. **整山 X 光透视模式（X-Ray）**：山体与混凝土外墙化为 12% 透明线框，整座避难所的 6 大管网与竖井像立体医学影像一样悬浮呈现（最震撼视图！）。

### 2.2 标志性房间程序化资产要求（确保一眼能认出是什么房间）
Codex 在 M2 构建程序化房间资产库时，每个核心房间应具备以下可辨识视觉锚点：
- **L2 观测厅与温室**：倾斜钢框大玻璃、屋顶白色圆球雷达罩、双翼可折叠蓝色光伏阵、温室种植池与几何低多边形绿植。
- **L1 车库与入口**：2 台精致几何全地形车、顶置明黄龙门吊、厚重带黄色警戒条的液压防爆门。
- **B1 立体仓库与工坊**：4 层高密度货架（上面按实时库存比例摆放蓝/灰/橙模块化周转箱）、绿色 5 轴 CNC 玻璃护罩机台、机械臂/打印舱、带指示灯的洗消喷淋拱门。
- **B2 居住、书房、医务与中控**：中控室弧形三联屏发光控制台 + 黑色服务器列阵（带微小绿/蓝闪烁灯）；10 间卧室可见整齐床铺、暖色书桌灯与顶部浅蓝模拟天窗；餐厅长木桌与顶灯；图书馆暖木书架墙；健身房力量架与跑步机；医务室纯白无影灯与负压玻璃隔间。
- **B3 农业与水处理**：5 层发光紫白补光灯水培架（托盘内满铺多层次绿叶簇，视觉极具生命力！）、透明蓝水循环鱼池、冷库银灰金属保温门与冷气机组、净水站 2 座立式不锈钢大型圆柱水罐（配透明液位观察条与蓝色管道群）。
- **B4 能源与配电**：2 座带重型混凝土屏蔽罩与垂直散热鳍片的微核堆（中心泛柔和青白/琥珀运行光）、整齐排列的电池储能机柜阵列、带多排压力表/滤芯把手的三防新风大风箱、深入地下岩层的地源热泵集分水器。

### 2.3 轻动态氛围（让沙盘“活起来”但不干扰观察）
- **管网微流光**：开启任意 MEP 图层时，管道/桥架表面沿真实流向（发电源 → 用电房，净水站 → 用水房，新风总站 → 正压房）缓慢移动柔和光点或流光条纹。
- **设备微动画**：屋顶风力机缓转、B4 风机叶片旋转、服务器指示灯微弱呼吸闪烁、B1 走廊小型 AGV 沿直线慢速滑行。
- **10 人比例尺极简小人**：采用建筑模型风的精致极简人形（高 `1.75m`，按主职配色带细微胸牌色环），在各自负责区域与走廊间慢速巡视；提供独立开关可随时隐藏，专注于纯建筑工程观察。

## 3. 灯光、材质与情景氛围

- **基础布光**：
  - 1 盏主方向光（投射柔和 PCF 软阴影，方位随情景变化）；
  - 1 盏半球环境光（天空冷蓝 + 地面暖灰）防止暗部死黑；
  - 地下各层通过轻量化暖/中性室内光与自发光材质（灯带、水培灯、屏幕）营造通透感，避免大量实时阴影点光源拖垮帧率。
- **四种情景的一键视觉切换**：
  - `日常`：明亮通透的清晨冷暖对比光，绿树与草坡；
  - `极寒`：低饱和冰蓝天光 + 坡面积雪材质切换 + 飘雪粒子 + 屋顶百叶半闭；
  - `生化`：淡黄绿低矮雾效 + 悬浮孢子粒子 + B1 洗消气闸红色警戒灯；
  - `核尘封锁`：暗琥珀灰沉降氛围 + 光伏折叠收起 + L1 重型防爆闸门闭合 + 地下切入稳重暖黄/应急光对比。

## 4. 交互与 HUD 界面设计

界面遵循 **“工程控制台极简风（Clean Precision HUD）”**：深炭磨砂玻璃半透明面板、细 1px 边框、等宽数字字体（Tabular Nums），让 **80%+ 屏幕面积始终留给 3D 沙盘**。

### 4.1 四向屏幕布局
- **顶部精简状态栏**：
  - 左侧：项目名称（`AEGIS RIDGE // 磐石山脊观测站`）+ 4 个情景切换胶囊（日常 / 极寒 / 生化 / 核封锁）+ 入住人数滑动条（5–10 人）。
  - 右侧：视图模式切换（全山外观 / 地质半剖 / X 光透视）+ 相机视角快捷键（全景 / 地表 / 地下剖面 / 第一人称漫游）+ 模式切换（`检视模式` / `模块调整`）。
- **左侧悬浮楼层剥离条（Floor Slicer）**：
  - 纵向按钮：`ALL（全显）` / `L2` / `L1` / `B1` / `B2` / `B3` / `B4`。
  - 选中单层时，其上方楼层与山体平滑隐藏或上移透明化，同时提供一个**“显示本层机电夹层”**开关，可单独掀开/盖上本层顶棚 `0.9m` 管网夹层，看清每一根强弱电与水管的真实走向！
- **左下角 6 大工程图层开关（MEP Layer Dock）**：
  - 6 个带规范色点的开关按钮：`强电` / `弱电` / `给排水` / `三防新风` / `物流吊装` / `结构防护` + `一键全开/全关`。
  - 开启任意图层时，未选中的建筑围护结构自动降低不透明度（进入轻度 X 光态），突出管网层次。
- **右侧可折叠工程检视与诊断抽屉（320–360px 宽，3 个标签页）**：
  1. **`体检报告（Feasibility）`**：5 大自持力仪表条（电/热/水/粮/气）+ 5 大工程合规审查清单（点击任何警告项，相机自动平滑飞往问题房间或管段并脉冲高亮！）。
  2. **`详情与检修（Inspect & Service）`**：点击任意 3D 房间、核心设备或管段后展示：真实尺寸、功率/流量、设计寿命、所需备件与 B1 库存、主/副修专家、可更换通道校验，并提供一颗醒目的 **`模拟隔离检修` 按钮**——点击后在 3D 中将该设备/支路标记为检修隔离态（红色虚线/闪烁），高亮自动接管的备用回路，并标出从 B1 仓库到该设备的绿色维修搬运路径！
  3. **`10 人团队（Crew）`**：展示 10 位专家卡片（支持自定义 AI 生图立绘头像，若无外部图则自动优雅降级为高质感矢量/几何徽章头像）、主副职标签与当前责任区；点击专家卡片高亮其管辖的所有房间与设备。

### 4.2 轻量模块替换交互（Phase 1 边界）
- 切换到 `模块调整` 后，蓝图中标记为 `可替换` 的房间（以及 B1–B4 的扩展位）显示淡青色可编辑边框。
- 点击该房间即可从侧边抽屉选择同规格备选模块（如将健身房换为扩展储能间，或将水产舱换为第二水培农场）并支持重置回“标杆预设”或导出/导入 JSON 蓝图存档。
- 每次替换立刻触发 `src/engine/` 重算管网连接与体检指标，让用户亲眼看到“多加一层水培会怎么吃掉电力和散热余量”。

## 5. 可选 AI 生图平面资产规范（资产路线 1 增值项）

本项目的 3D 主体由代码 100% 程序化完成，AI 生图仅用于锦上添花的 2D 平面资产，放置于 `public/assets/`：
- `public/assets/crew/crew_01.png` ~ `crew_10.png`：10 位专家的统一画风科研/工程半身立绘（冷暖工装、干净浅灰背景、1:1 比例）。
- `public/assets/blueprints/*.png`（可选）：核心设备详情卡里的工程剖面示意图。
- **优雅降级要求**：前端必须支持在图片尚未生成或缺失时，自动回退为风格统一的几何标识 + 专业徽章，绝不显示破图图标。
