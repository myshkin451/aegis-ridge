# 02. 双语域视觉圣经与仪器 HUD 规格（v2.0）

> **根本转向**：彻底推翻 `v1.0` 导致的“深海军蓝 + 香槟金 + 磨砂玻璃 SaaS 仪表盘 + 39m 纸板等高线蛋糕山”视觉错位。整件作品确立**“山外是实景，剖开是图纸”的双语域美学**：站在山外看，是真实尺度的高山、物理天空、空气透视与云海；一旦剖开，一切剖切面、标高、轴网、图例与读数都严格遵守建筑与地质制图规范。

## 1. 双语域设计哲学与“去 AI 味”铁律

### 1.1 明确禁止的“AI 模板元素”
在 UI 与 3D 场景中严禁出现以下元素：
- ❌ 上下实心深色顶栏/页脚横幅（必须 **100vw × 100vh 全屏出血画布**）；
- ❌ 圆角毛玻璃卡片（`backdrop-filter` 浮卡 + 大阴影）、香槟金品牌强调、iOS 式拨动开关；
- ❌ 毫无实际信息载荷的线性装饰图标墙、假装在线的绿色呼吸点、常驻底部鼠标手势教条、大圆角山峰 Logo 块；
- ❌ 呼吸灯、外发光、扫光、弹簧回弹、视差倾斜动效；
- ❌ 径向渐变黑洞背景、1.2m 等厚纸板台阶山、平底托盘底座、同色圆锥火车模型树。

## 2. 字体、线型、全屏 HUD 与动效规范

### 2.1 四种字体角色与四级字号
- **界面**：思源黑体（`Noto Sans SC` / 系统黑体回退），**中文不加字距**。
- **图纸标注**：长仿宋（遵循 GB/T 14691，优先系统仿宋 `"STFangsong", "FangSong", "FangSong_GB2312"` 配合 `scaleX(0.74)` 模拟长仿宋比例；若引入开源 **朱雀仿宋（OFL）** 必须严格按图纸字符子集化并保留系统仿宋回退，严禁整包加载拖垮首屏）。
- **数值与读数**：`IBM Plex Mono`（开启 `font-variant-numeric: tabular-nums`）。
- **拉丁工程标签**：`IBM Plex Sans Condensed`（如 `ARS-01`、`SECTION 1-1`、`SHEET A-203`）。
- **严格四级字号**：`11px` 读数、`13px` 标签、`16px` 正文、`22px` 图名。

### 2.2 全屏仪器 HUD 架构（四大常驻件 + 按需浮层）
全屏画布铺满视口，HUD 贴四边留白 `24px`（窄屏 `16px` + safe-area），线宽只用 **`1px` 细线与 `2px` 剖切线**，圆角严格 **`0–2px`**，无投影、无渐变：
1. **左上 · 工程图签（Title Block）**：3 行 2 列细线表格——
   - `磐石山脊高山生态与气象观测站` | `ARS-01`
   - `当前图名（如 剖面 1-1 · 地质半剖）` | `投影与焦距（如 透视 · 50 mm）`
   - `±0.000 = 海拔 1450.000 m` | `时刻 · 工况（如 07:40 · 日常 / 封锁 · 第 1 天）`
2. **右上 · 纯文字视图切换**：`现场¹  剖面²  平面³  X光⁴  漫游⁵`（无圆角背景框，选中态用 `2px` 下划线 + 右上角单字符快捷键标；情景切换与 24h 时间轴紧凑收纳在图签或次级行，不占屏幕中部）。
3. **左侧 · 真实比例标高尺（Elevation Ruler）**：彻底取代旧楼层按钮卡片！
   - 尺上每一像素按真实米数严格成比例：`6.0m` 防护岩层填充花岗岩 `+` 字纹，视觉厚度明显厚于 `4.2m` 单层；楼板按剖切惯例涂黑，顶部 `0.9m` 机电夹层填 45° 细斜线。
   - 点击任意一层即切换楼层；**尺上配一枚可拖动的修改红 `FL+1.200` 水平剖切游标**，实时控制平面/单层水平剖切高度（默认楼面以上 `1.2m` 窗台线）。窄屏自动横置到底部。
4. **左下 · 线型图例（情境显示）** + **右下 · 实时读数与分段比例尺**：
   - 左下仅在进入剖面/平面/X 光或开启图层时显示极简 6 大系统线型勾选清单（含 `M` 夹层勾选，不再用 iOS 拨动开关）；
   - 右下常驻光标处实时坐标/标高/轴号（`X 4.21  Z −1.73  ▽ −14.400  轴 C/7`）+ 建筑分段比例尺（`0–5–10–20 m`）+ 极简单色指北针。
5. **右侧 · 按需数据表（仅选中房间/设备/打开体检或专家时出现）**：`1px` 细线直角表格，直接呈现面积、标高、净高/夹层、负荷、主副责专家，底部双格操作条（`进入漫游 W` | `隔离检修`）。
6. **键盘优先 & 首次进场动效**：
   - 快捷键：`1–6` 切层、`V` 切视图、`M` 夹层、`X` X 光、`W` 漫游、`F` 聚焦、`H` 隐藏 HUD（出片用）、`?` 显示快捷键（首次进入显示一次操作提示后消失）。
   - 状态切换 `120ms`（`cubic-bezier(.2,0,0,1)`，不位移）；楼层剥离每层 `360ms` 错开 `40ms`；进图纸视图时 `600ms` 绘图仪式描出剖切线与轴网；首次加载先约 `1.5s` 描出剖切线与轴网再填入材质与光照，同时优雅掩盖构建期资源载入。

## 3. 四尺度真实侵蚀山体与地质剖切面

### 3.1 修正尺度错误（告别 39m 矮山）
M1 山体仅 `39m` 高，站点几乎坐在山顶。`v2.0` 建立真实的四个地形尺度：
1. **远景山脉层（10 km 范围）**：低多边形层叠山脉剪影（5–7 层，遵循中国山水“平远”与瑞士 Eduard Imhof 地形晕渲原则：受光偏暖、背光偏冷蓝紫、高处对比强、低处渐融于空气透视雾）。
2. **主山侵蚀高度场（2–3 km 范围）**：站点海拔 `1,450 m`，上方仍有约 `600 m` 主山脊，下方下切约 `300 m` 山谷，含东西两条真实冲沟（东侧冲沟 270m 外下切至 `1,435 m` 承接 B2 远端逃生平硐，下部 `1,240 m` 承接重力排水涵洞）。
3. **场地高精度整形块（300 m 范围）**：用 SDF 将站点平台、之字形进站路（半挖半填、边沟、波形护栏、石笼挡墙）、防雪崩廊道、挖方喷射混凝土与岩钉边坡精准刻入高度场。
4. **可剖切核心地质体（80 m 见方）**：围绕地下综合体，与外部地形无缝咬合。

### 3.2 构建期预计算管线（纯代码、零首屏卡顿）
- 使用 Node 构建期脚本（固定种子，确定性输出）基于 `ridged multifractal + domain warp + 水力侵蚀 + 热侵蚀（约 35° 倒石堆安息角）` 预计算产出 16 位高度图与 **五张驱动图**（高度、坡度、曲率、汇流量、坡向）随包发布。
- 所有坡面材质边界与分带植被（针叶林、灌丛、高山草甸、岩壁、倒石堆、背阴积雪）**全部由五张驱动图驱动**，彻底消灭均匀撒布的火车模型树和人为高度硬线。

M1.5a 的四幅测区边长依次为 10,000、2,400、300 和 80 m。两处硐口另以核心测区的 0.625 m 采样间距加密，边缘接入上一级三角网。针叶树采用程序化枝片，近处保留枝轮与林下灌丛，远处按地块切换为较疏的树冠。

### 3.3 地质剖切面规范（切开即是博物馆级地质剖面图）
- 剖切面为真正的几何平面（地形部分解析采样生成精准切面多边形；建筑实体部分采用 Three.js clipping stencil 封口）。
- 切面着色器按世界坐标投影标准**地质与建筑材料图例**（随剖切面移动保持真实尺度不变）：
  - 自上而下：**表土（斜短线）→ 风化花岗岩（`+` 混点）→ 新鲜花岗岩（标准 `+` 字纹 + 两组陡倾节理 + 一组缓倾节理 + 浅色细晶岩脉）**；
  - `6.0 m` 复合防护层必须分层绘制：**上部 `1.5m` 钢筋混凝土图例（三角点纹 + 45° 线）+ 下部 `4.2m` 与山体连续的新鲜花岗岩**；
  - 绘出蓝色虚线与 `▽` **地下水位线**；所有被剖切轮廓线宽 `2px`，可见轮廓 `1px`。
- 从“现场”切到“剖面”时，剖切面前方山体平滑向南平移约 `40m` 并淡出（模型拉开仪式感，非瞬间消失）。

## 4. 程序化 PBR 材质库与全局倒角纪律

### 4.1 两条不可违背的造型与材质铁律
1. **全局 5–20 mm 倒角**：所有建筑体块与核心设备棱边均做物理倒角或法线倒角，让真实光线接住高光，彻底消灭锐利 CG 方块感。
2. **三层材质复合**：基础色与粗糙度 + 曲率/AO 驱动的边缘磨损与积灰 + 朝向/重力驱动的竖向雨痕与水渍。

### 4.2 10 种程序化 PBR 材质清单（WebGL2 GLSL / Canvas 生成）
| 材质 | 应用部位 | 核心程序化算法 |
| --- | --- | --- |
| 1. 新鲜花岗岩 | 剖切面、崖壁、挖方面 | Worley 晶胞三相（长石 55%、石英 30%、黑云母 15%）+ 低频色差与微法线 |
| 2. 风化岩与地衣 | 岩脊露头、碎石坡 | 曲率/坡向驱动，凸处长黄绿（`#B8B36A`）与橙色（`#C47B35`）高山地衣斑 |
| 3. 碎石坡与高山草甸 | 山坡表面 | 坡度 `>35°` 露岩、`30–35°` 碎石、`<30°` 草甸；高汇流沟底更湿更深绿 |
| 4. 积雪 | 背阴坡、沟槽、屋面 | 按坡度/朝北/海拔/风向沉积，风蚀波纹法线 + 极细镜面雪晶闪点 |
| 5. 清水混凝土 | 挡墙、平台、硐口、地下主体 | 模板条纹、规律排布对拉螺栓孔、浇筑分层色差 |
| 6. 喷射混凝土+岩钉 | 挖方边坡、平硐壁 | 粗砺凹凸噪声表面叠加规律岩钉垫板与泄水孔阵列 |
| 7. 耐候钢（Corten） | 门框、护栏、外围设备罩 | 锈色 fBm + 窗台与横梁下方竖向雨痕流挂 |
| 8. 风化落叶松外挂板 | 地表观测站外墙 | 竖向木条与缝影，檐下保持新木色（`#B9895A`）、下部受风雨风化为银灰（`#A3A199`） |
| 9. 低铁建筑玻璃 | 幕墙、温室、B2↔B3 防火中庭 | `MeshPhysicalMaterial`，真实天空反射与极淡绿边 |
| 10. 环氧地坪与钢格栅 | 地下各层地面与 B4 机房 | 轻橘皮微粗糙度，划痕与磨光方向沿走廊 AGV 轨迹分布 |

## 5. 物理天空、云海、分楼层光温与后处理

### 5.1 天空、云海与后处理（WebGL2 稳健管线）
- **物理天空与大气**：基于真实太阳高度角/方位角（接入 24h 时间轴）的 Rayleigh + Mie 物理天空着色器 + 距离与高度双重空气透视雾，确保高稳健度、不依赖易碎的实验版第三方云包 API。
- **山谷逆温云海**：在低于站点平台（约 `1,200–1,380 m`）的山谷层构建多层动画噪声体积云片，营造“站点悬于云海之上、远山浮于云中”的招牌黎明画面。
- **色调映射与后处理**：
  - **`AgX` Tone Mapping**（比 ACES 保留更真实的高光色彩，不发假橙）；
  - **`N8AO`**（环境光遮蔽，赋予墙角、设备底座与管道真实重量感）；
  - **选择性 Bloom**（仅作用于灯具、屏幕、指示灯与 X 光管网，绝不泛白整幅画面）；
  - **SMAA 抗锯齿 + 4 种情景专用 3D LUT**（日常 / 极寒 / 生化 / 核封锁，克制调色不加廉价滤镜）+ 极轻胶片颗粒消除天空色带；
  - **4 档动态画质分级**（依据帧率在阴影级联数、AO 分辨率、植被密度、DPR 间平滑调节，守住主流笔记本 60 FPS）。

### 5.2 分楼层光温叙事与 24 小时节律时间轴
| 楼层 | 主光温与氛围 | 特色点缀 | 空间情绪 |
| --- | --- | --- | --- |
| **L2** | 真实物理天光随 24h 变化 | 夜间 `2700 K` 室内暖点 | 开阔通透 |
| **L1** | `4000 K` 公共中性白 | 车库琥珀警示灯 | 寻常科研机构 |
| **B1** | `4500 K` 工业中性 | 黄黑吊装斑马线、AGV 状态灯 | 有序作业 |
| **B2** | **`2200–5000 K` 24h 节律照明**（夜间 `1800 K` 低位琥珀踢脚灯） | **中控室 `23:00–06:30` 潜艇式红光暗适应**、餐厅一束光纤真阳光 | 温暖私密 |
| **B3** | **全光谱偏品红白补光**（拒绝夜店红蓝紫；**`20:00–12:00` 夜间错峰 16h 运行**） | 鱼池水蓝焦散、冷库 `6500 K` | 蓬勃生机 |
