# 05. 相机状态机与第一人称漫游规格（Camera & Walkthrough Spec）

> **核心原则**：正交投影只属于平面图与剖面图，透视长焦属于高山实景，60° 广角人眼属于“住进去”。六个相机状态之间全部通过连续镜头运动衔接，用户永远清楚自己从哪来、此刻身处海拔几米。

---

## 1. 六状态相机状态机

底层通过 `camera-controls` 实例统一管理非漫游状态（取代基础 `OrbitControls`，自带临界阻尼平滑、`fitToBox`、向光标缩放与边界约束）；漫游状态由定制 `WalkthroughRig` + `three-mesh-bvh` 接管。

| 状态 ID | 名称 | 投影与镜头 | 机位特征 | 核心控制 | 主要用途 |
| --- | --- | --- | --- | --- | --- |
| `site` | **现场**（默认首屏） | 透视，等效 `50–85 mm`（垂直 FOV `16°–27°`） | 俯角 `8°–25°`，画面含真实地平线、云海与远山 | 鼠标环绕/平移/推拉 + **`WASD/QE` 自由飞行**（防钻地/防穿楼） | 理解半山腰选址、外观与 19 处外围设施 |
| `section` | **剖面** | **正交**（支持一键切换透视） | 垂直于南向地质剖切面 | 平移、缩放、拖动剖切面位置 | 读层高、6m 复合防护层、竖井对齐与地质图例 |
| `sectionBox` | **剖切盒** | 透视 `35 mm`（垂直 FOV `38°`） | 自由三维视角 | 拖动六个切面手柄（吸附轴线/墙线）+ **`WASD/QE` 自由飞行** | 任意切开某一层、某个机房或核心筒 |
| `plan` | **平面** | **正交** | 垂直俯视 `90°`，默认剖切高度 `FL+1.200`（可由标高尺红游标拖动） | 平移、缩放 | 读房间平面布局、轴网、干湿分区与编号 |
| `floorOrbit` | **楼层俯瞰** | 透视 `35 mm` | 俯角 `35°–50°`，上部楼层原地淡出 | 环绕单层 + **`WASD/QE` 自由飞行** + 点击地面落地 | 细看某层设备、选房间进入漫游的过渡态 |
| `walkthrough` | **第一人称漫游** | 透视，垂直 FOV `60°`（可调 `50°–75°`） | 真实眼高 **`1.65 m`** | 默认点地移动 + 键鼠 WASD / 触屏摇杆 | 真正走入避难所走廊、房间、温室与平硐 |

### 1.1 3D 自由飞行、相机防穿模与可打断转场（M1.5b 返修硬规格）
- **3D 透视视图自由飞行（Free-Fly）**：在 `site`、`sectionBox`、`floorOrbit` 与 `xray` 透视模式下，除鼠标环绕外，直接支持 **`W/A/S/D` 沿视向水平平移飞行、`Q/E` 垂直升降、`Shift` 加速**；飞行速度随相机离地/离建筑高度自动连续缩放（低空贴近细节约 `6 m/s`，高空俯瞰山谷平滑提升至 `40–80 m/s`），避免与视图键冲突（统一采用 `1–5` 切视图、`[`/`]` 切层、`WASD/QE` 专职移动）。
- **相机防穿模边界**：在 `site` 视图中，利用已有的地形高度场强制约束轨道/飞行相机始终位于地表以上 `≥ 0.8 m`，并对站房主建筑外廓施加简化防穿入包围盒与合理最小推近距离（杜绝滚轮推近直接钻入山坡或混凝土墙内）；在 `sectionBox` / `floorOrbit` / `xray` 模式下允许自由逼近检视内部。
- **避障过渡与随时打断**：所有视角切换转场不再做生硬穿过山体或楼板的直线插值，改用避开地形与屋面的平滑弧线；且**任何一次指针拖拽、滚轮或移动按键都必须立即打断正在播放的过渡动画**并将控制权平滑交还给用户。
- **动态深度裁面**：室外视图采用 `near ≥ 0.5 m / far 15 000 m`，漫游视图切换为 `near 0.12 m / far 350 m`，避免 `0.07 m ~ 16 km` 过度拉伸导致远山深度闪烁。

M1.5b 的“机位与图幅”提供剖切盒与楼层俯瞰。平面点击房间弹出蓝图数据表，俯瞰点击房间地面直接落地。剖切盒支持拖动场景内六个红手柄，也可以在屏上选面并调整滑杆。投影转场在目标平面上保持每米的屏幕比例；系统开启减少动态效果时直接到达目的机位。

## 2. 五个招牌镜头转场

1. **竖井下潜（`site` → `walkthrough`，全站招牌转场）**：
   - 当用户从外部实景直接进入地下某层漫游时，相机先飞至 L1 重载吊装口上方，随后沿 `gx=5..6` 货梯井垂直下潜；各层楼板切口与竖井壁上 **`1.2 m` 高超大层号**（`B1 / B2 / B3 / B4`）从镜头掠过，左上角图签标高从 `±0.000` 实时滚动跳变至目标层（如 `▽-18.600`），到层后平滑转身步入主走廊停在目标房间门口。总时长 `3–4 s`，任意点击或按键立即跳过。
2. **掀顶落地（`floorOrbit` → `walkthrough`）**：
   - 在楼层俯瞰状态下点击任意房间地板（或点数据表 `进入漫游 W`），相机沿弧线下落，俯仰角逐渐放平，吊顶与机电夹层淡出，FOV 由 `38°` 平滑放宽至 `60°`，稳稳落在 `1.65 m` 眼高并朝向该房间预设的最佳机位锚点（`RoomCameraAnchor`）。
3. **拉出（`walkthrough` → `floorOrbit` → `site`）**：
   - 按 `Esc` 键，相机带轻微阻尼动量向后上方拉起，墙体与上层结构平滑恢复，退回楼层俯瞰（再按一次退回现场）。
4. **投影变形（透视 ↔ 正交，Dolly-Zoom Morph）**：
   - 从透视现场切入正交剖面/平面时，用变焦推拉同步拉长焦距并后退相机，保持主体在屏幕上尺寸恒定，逼近极长焦后再无缝切换为正交相机，彻底避免视角突变丢失方向感。
5. **山体前移（`site` → `section`）**：
   - 切入地质剖面时，剖切平面前方的山体整体向南平移约 `40 m` 并渐隐淡出，像拉开一套精密的建筑地质模型。

## 3. 第一人称漫游手感与交互规格

| 维度 | 工程与手感设定 |
| --- | --- |
| **双模移动（零门槛优先）** | **默认点地移动**：鼠标悬停地面出现简洁 1px 落点圆环，单击平滑滑行至目标点（类 Matterport，非游戏玩家也能轻松逛遍全站）；随时按 **WASD / 方向键** 或进入指针锁定自由步行；触屏提供左虚拟摇杆 + 右手滑动转向。 |
| **速度与舒适度** | 常规步行 **`1.4 m/s`**，按住 `Shift` 快走 **`2.5 m/s`**，`0.25 s` 平滑加减速；默认关闭镜头晃动（防 3D 眩晕，设置中可选开启）。 |
| **物理碰撞与楼梯** | 胶囊碰撞体半径 `0.25 m`、总高 `1.75 m`，基于 `three-mesh-bvh` 精确执行贴墙滑动与防穿模；台阶自动抬升上限 `0.20 m`，可顺着 `gx=7..8` 合规双跑楼梯与 `gx=14..15` 东侧疏散楼梯步行上下楼，并可步入西南 60m 平硐与 B2 东端 270m 远端逃生平硐。 |
| **普通门与三防气闸门** | 普通内门靠近自动平滑滑开；**防爆气闸门（L1 互锁前厅、B1 洗消间、双平硐口）需长按 `E` 键开启**——触发门旁压差表指针实时平衡、`1.5 s` 泄压音效后闸门滑开，让三防正压梯度成为可感知的身体体验。 |
| **竖线与曝光适应** | 相机平视时保持建筑竖线端正；明暗房间切换（如暗走廊步入 B3 农场、地下步出 L2 阳光温室）做 `0.8–1.5 s` 人眼自动曝光适应。 |
| **漫游精简叠加** | 屏幕中央仅 1 枚极小准星点；准星悬停设备时显示位号读数（如 `P-301A 净水提升泵 · 运行`）；左下极简当前层小地图（含视锥朝向）；左上图签实时更新当前所在房间名与标高。 |
| **性能优化** | 漫游态自动仅高精渲染当前层与相邻层，跨房间按门洞做可见性裁剪，守住 60 FPS。 |

## 4. 漫游与建筑师专属招牌工具

- **Alt 键 X 光透视透镜（M3 接入管网后全功能激活）**：漫游时按住 `Alt`，以鼠标光标（或屏幕中心）为圆心浮现一片圆形透视区，墙面与吊顶局部透明，直接看穿墙后桥架与管道走线。
- **抬头看夹层**：在地下主走廊中仰视超过 `30°` 时，顶棚饰面板自动转为半透明，露出 `0.9 m` 顶部机电检修夹层内的强弱电桥架、风管与吊轨。
- **房间机位锚点与晨间巡检（M2 建锚点，M5 接导览）**：每个房间定义 `1–3` 个建筑摄影级机位锚点；M5 接入 10 人团队后支持沿指定专家的真实路线自动慢速巡检并配工程解说字幕。
- **两点毫米级测距（M6）**：在任意图纸/剖面/俯瞰视图中开启测距，吸附建筑顶点与墙边，实时在 3D 场景中标注精确到毫米的距离（如走廊净宽 `2 000 mm`、核心筒尺寸 `4 000 mm`）。
- **照片模式（M5）与视角深链接（M6）**：一键隐藏 HUD、开启轻微景深与移轴垂直校正、支持 `16:9 / 4:5 / 2.39:1` 画幅导出高清截图；每个机位可编码为 URL 参数实现一键复现。
