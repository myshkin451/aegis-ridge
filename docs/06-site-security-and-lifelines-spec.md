# 06. 外围地景、隐蔽安保与逃生生命线规格（Site, Security & Lifelines）

> **核心原则**：这不是军事基地，没有营房、哨塔和兵力。整座半山腰外围体系的最高美学与工程准则叫做**“藏于科研”**——每一处安保屏障、每一条生命线和每一个逃生口，都对应高山科研站或山地土木工程里完全寻常、说得通的明面设施。

---

## 1. 四条总体原则

1. **藏于科研**：严禁出现铁丝网、岗楼、迷彩、橄榄绿、射击孔、探照灯、军用相控阵雷达、“军事禁区”字样。参考斯瓦尔巴全球种子库、少女峰斯芬克斯观测站、楚格峰 Schneefernerhaus 环境研究站的极简克制气质。
2. **纵深交给地形**：利用山谷入口 → 之字形盘山路 → 防雪崩廊道 → 公共门厅 → 互锁防爆前厅 → 6m 复合防护层与核心竖井层层收窄。
3. **生命线多源、分向、可切换**：电（光伏试验场 + 屋顶风电 + 地下双微核）、水（上游山泉重力引水 + 闭环再生 + 消防蓄水池）、气（山脊两侧双进风口按风向切换）、物流（之字形公路 + 山谷货运索道）、通讯（屋顶雷达 + 邻峰中继 + 沿逃生平硐埋地光纤）全部互为异向备份。
4. **逃生口远离、换向、低可见**：除主出口与 B1 近距检修平硐外，远端主逃生平硐从 B2 居住层向东深埋穿山约 `270 m`，在另一条汇水冲沟、朝向不同视线方向低姿态出露。

### M1.5a 模型中的标高与接点

B1 检修平硐从洗消间西墙出发，先向西 22 m，再转向西南 38 m，在挡墙出露。B2 东端楼梯的西平台接主走廊，平层通路经居住区北缘绕开上行梯段，从东墙接入平硐。东硐 270 m 的水平长度产生 0.810 m 的高差，洞底由海拔 1,435.600 m 降至 1,434.790 m。里程 135 m 处侧接避难硐室。

覆岩按地表到**硐顶**的垂直距离量取。里程 24–246 m 为覆盖校核段，测试每米采样，进站段和洞口过渡段另验实际净空与出露标高。B4 楼面至海拔 1,240 m 排水出口的实算高差是 187.2 m。场址数据同时记录山泉、排水和两路进风的系统接点。

## 4. 30 秒封锁编排（Lockdown Choreography，M4 落地）

当情景由 `日常` 切入 `生化孢子潮` 或 `核尘埃全面封锁` 时，3D 场景执行一段克制而震撼的 **30 秒联动封锁编排**（支持跳过或回放）：
- **`0 s`**：盘山路隐蔽地柱升起，防雪崩廊道内藏重型钢闸门平滑落下。
- **`5 s`**：L1 公开门厅灯光熄灭，幕墙内侧 4 吨液压装甲防爆门滑出锁闭。
- **`10 s`**：L1/L2 外立面落叶松木百叶旋转闭合，露出内侧高强防护板。
- **`15 s`**：L2 阳光温室屋面保温防护板合拢，光伏试验场与屋顶光伏翼折平锁紧。
- **`20 s`**：屋顶测地雷达罩依旧平稳缓慢旋转——从外部看，科研站只是在大风雪里进入无人值守状态，彻底隐匿地下生机。
- **`25 s`**：若处于自动导览态，镜头沿核心井下潜至 B1，洗消间正压警戒红灯亮起，门旁压差表指针升至设定正压差。
- **`30 s`**：左上角工程图签情景栏切换为 `封锁 · 第 1 天`，工程引擎同步切入全密闭热/氧/水/电校核模式。
