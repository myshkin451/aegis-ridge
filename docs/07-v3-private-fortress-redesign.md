# 07 — v3.0 私人硬核高山堡垒重构方案（6–8 人版）

> 本文档确立 **Project Aegis Ridge v3.0** 的新定位与空间、交通、体验改版方案。  
> 在完整保留已有真山体、实拍地表与林木、物理天空与暴雪、坚固地上外立面、建筑剖切与渲染底座的前提下，彻底告别“高山科研站 / 10 人专家团 / 满屏红字物理审计”，转向**给 6–8 位同伴长期安心居住的私密硬核地下堡垒**。

## 3. 四大体验根治工程规格

### 3.1 彻底消除材质拖动闪烁（Z-fighting / Shimmering）
1. **消除薄贴片重面**：审计并修正 `residentialFinishes.ts`、`floorFinishes.ts`、`SurfaceStation.tsx`、`StationClosures.tsx`、`BuildingSection.tsx` 中所有与结构墙/地板间距 `< 12 mm` 或重叠的饰面板、地毯条纹、门窗框与百叶（实墙内饰面距墙面净偏置统一 `≥ 15 mm`，地毯条纹高于地毯顶面 `≥ 3 mm` 并开启 `polygonOffset`）。
2. **优化深度缓冲精度**：室内漫游与单层视图动态收紧相机裁剪面（漫游 `near: 0.15, far: 220`；剖面/平面/楼层俯瞰 `near: 0.3, far: 800`；外景 `near: 0.8, far: 12000`），大幅提升 24-bit Z-buffer 在中近景的有效位数。
3. **全局纹理各向异性过滤与抗闪烁**：在 `pbrLibrary.ts`、`finishAtlas.ts`、`terrainScans.ts` 中对所有采样纹理启用 `anisotropy = Math.min(8, gl.capabilities.getMaxAnisotropy())` 并确保三线性 mipmap 开启；调整 `N8AO` 与阴影 `bias/normalBias`，消除拖拽镜头时的细边与墙角抖动。

### 3.2 真可用双电梯、货梯装卸与全楼导视
1. **双电梯真实运行状态机（`src/geometry/elevators.ts`）**：
   - **人员客梯**：停靠 `L2 / L1 / B1 / B2 / B3 / B4` 全 6 层，井道内有真实可见轿厢、内外联动门扇；
   - **3t 重载货梯**：停靠 `L1 / B1 / B2 / B3 / B4` 全 5 层，L1 车库卸货区增设规范双开货梯门与装卸框；
   - 第一人称走近电梯门自动感应开门（若轿厢在别层则平顺呼梯到达后开门）；走入轿厢后，屏幕右侧轻巧弹出 **电梯楼层按键板**，点击任意停靠层即关门、播轻微电机/报站提示音并平稳升降至目标楼层后开门。
2. **全楼清晰实体导视（升级 `FloorSigns.tsx`）**：
   - **电梯厅主总览牌**：L2–B4 每层人员电梯门对面/旁侧挂高对比度大号楼层总览牌（标明当前楼层号、功能定位与左右方向房间箭头）；
   - **货梯装卸区标识**：L1 & B1–B4 货梯门上方挂 `3T 重载货梯` 安全黄黑铭牌，地面刷清晰黄黑装卸框与通行箭头；
   - **全楼门牌**：每一扇可进入的房间门旁统一安装中文门牌（如 `B1-02 武器与战术工具库`、`B2-01 影音与游戏室`），漫游时抬头一眼识路。

### 3.3 视角切换与第一人称顺手度改造
1. **取消强制长绕路动画**：外景/剖面/平面点击任意房间或切漫游时，改为 `0.5–0.8 s` 干脆平滑直达目标位置（不再强制绕车库钻货梯井）；原 75 s 开场导览收至右下或菜单内按需播放，且任意输入瞬间打断。
2. **第一人称自然手感**：加入柔和的起步/刹停速度阻尼（消除生硬启停与漂浮感）、更宽容的门洞碰撞清理（绝不卡门框）、稳定的鼠标拖动环顾与点击地面行走，并**彻底移除近景出戏的哑光绿胶囊巡检小人**。

### 3.4 UI 大减法与黑盒系统状态
- **精简顶栏**：
  - 左侧简洁图签：`磐石山脊 · 私人高山堡垒` + 当前楼层/视图 + 情景切换（`日常晴天` / `极寒暴雪` / `全面封锁`）；
  - 右上核心模式：`外景 1` · `剖面 2` · `平面 3` · `漫游 4`；
  - 右上简洁工具：`堡垒状态`（黑盒总览抽屉）· `房间直达` · `拍照` · `键位 ?`。
- **移除/收起冗余面板**：取消“10 人专家团”“模拟隔离检修”“满屏红字物理审计”“6 大管网细分勾选”“蓝图模块合规试装”等前台常驻入口（保留简洁的一键视角分享链接与拍照高清导出）。
- **黑盒状态卡片**：直观展示 5 项易懂指标——**主能源与储能**、**净水与农场自给**、**三防正压空气**、**B1/B3 战略物资储备（预计可支撑数年）**、**安防与封锁状态**。日常与暴雪态保持健康绿/蓝运行态，点击“一键全面封锁”完整触发 30 秒外立面百叶、车库装甲门、防爆气闸与应急灯光联动。

## 4. 三阶段分步落地路线（每步完成皆可直接进浏览器体验）

### 阶段 V3-1：根治闪烁 + 界面大减法 + 真双电梯与顺手漫游（优先体验翻盘）

- 精简顶栏与 HUD，下线专家团/检修/红字审计/管网细分/模块试装面板，替换为清爽的“堡垒黑盒状态”卡片与情景/封锁控制；
- 实现 `L2–B4` 真可乘人员客梯与 `L1–B4` 真可乘重型货梯（含轿厢内交互楼层按键板与门扇联动）；
- 取消切漫游强制钻井长动画，优化第一人称阻尼/门框通过性，移除出戏胶囊小人。

### 阶段 V3-2：六层空间去科研化重组 + 大仓库/武器库/影音游戏室/宽敞卧室 + 全楼导视
