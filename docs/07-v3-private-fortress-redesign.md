# 07 — v3.0 私人硬核高山堡垒重构方案（6–8 人 · Web 视觉上限原型）

> 本文档为 **Project Aegis Ridge v3.0** 的设计蓝图与四阶段落地路线（`V3-1` → `V3-4`）。  
> 旧版 v2.0 科研站合规验证器已完整归档于 Git Tag `v2.0-research-station`；从本版起，全部重心转向**视觉真实感、居住舒适度、囤货安全感与顺手交互**。

---

## 1. 核心定调：做你想走进去待着的地方

- **身份**：深山无人区半山腰的 **6–8 人私密硬核地下堡垒**，不做对外科研站伪装。
- **四种核心感觉**：
  1. **安全感**：厚重装甲门、堆满货架的大仓库、武器与战术工具库、低声可靠运转的黑盒机房；
  2. **舒服**：混凝土结构配暖橡木、布艺/皮革软装与克制明暗层次，进去像家而不是实验室或病房；
  3. **掌控感**：一眼清晰的系统状态卡、一键 30 秒封锁、客梯（`L2–B4`）与大货梯（`L1–B4`）真可乘、全楼中文门牌导视；
  4. **可信**：6–8 人常住负荷约 `15–25 kW`，B4 采用合理的**静音柴油/燃气发电机组 + 地下油库 + 大容量储能电池 + 地热供暖**（彻底淘汰旧版微核堆），物资储备年限与实际可见货架容量做轻量合理联动，系统状态名副其实地健康。
- **美术与资产策略（彻底告别“手写方块拼家具”）**：
  - 保留程序化几何做建筑结构壳体、梁柱、楼梯、电梯井、货架主骨架与山体地形；
  - 软装家具、车辆、厨电、绿植、周转箱、武器/工具道具全部转向 **CC0 真实 3D 模型（`.glb`，保留原装 PBR 材质贴图与 Draco/WebP 压缩）**；
  - 室内光影压暗全局大白底光，靠 `2700K` 暖色吊灯、壁炉、柜底灯带、床头灯与挑空中庭绿植光拉开明暗对比与墙角暗部层次；
  - 是否引入 Blender 为静态墙地顶补烘一层 Cycles 间接光贴图，留待 **V3-2 样板间** 肉眼验货后再定（零提前折腾）。

## 2. 六层空间规划与体验目标（沿用现有地下壳体与实墙外立面）

> 下面以“推门第一眼看到什么氛围”为最高目标，不做死板的拍脑袋平米数硬约束，确保空间比例舒展自然、不破坏外墙水密性。

- **L2（`+4.4 m` · 山景瞭望客厅与阳光暖房）**：
  - 拆除气象排桌与天文望远镜，西半部为面对山谷云海的私密观景沙发/暖炉/咖啡吧与紧凑安防监控位；东半部为满目绿意的阳光花房与休闲茶桌；灾变/极寒时外部重型百叶一键封合。
- **L1（`±0.0 m` · 实用重装车库、大货梯装卸与防爆入口）**：
  - 取消科研科普门厅，改为一眼看懂的三区：**双车位重装车库**（硬派越野车 + 履带雪地拖车 + 满墙汽修工具 + 直连 **`2.6 m × 3.0 m` 3t 大货梯**装卸框）、**防爆主入口与核心电梯厅**（正对大幅全楼索引牌）、**户外防寒装备更衣与物资预检间**（8 人防寒服/装备烘干柜 + 简易洗消 + 拆箱台）。
- **B1（`-10.2 m` · 战略大仓库、武器工具库与综合工坊）**：
  - 东南大跨空间做成塞满重型钢货架、周转箱、桶装水粮与日用物资的震撼主仓库；东北天然干区做成带重门与满墙枪柜/战术装备架/恒湿箱/保养台的**武器与防护工具库**；北中段紧邻货梯后门做卸货拆箱与重工具间；南中段做满配木金工维修工坊；西南做力量健身与康复室；西北保留西平硐应急洗消气闸。
- **B2（`-14.4 m` · 6–8 人温馨居住与影音游戏层 — 样板间首选）**：
  - **挑空客厅与开放大厨房（`b2_commons`，V3-2 首个满分样板间）**：参照 [ref-a-living-dining.jpg](references/b2-living/ref-a-living-dining.jpg) 与 [ref-b-open-kitchen.jpg](references/b2-living/ref-b-open-kitchen.jpg)——清水混凝土梁柱配暖橡木护墙板、嵌墙暖壁炉、深陷式皮布组合沙发、核桃木长餐桌、2700K 暖吊灯与柜底暗藏灯带、深色石材中岛与双门冰箱、挑空玻璃绿植中庭，墙角与天花外圈刻意压暗出电影级层次；
  - **东北私人影音与游戏室（原中控大厅整间转型）**：木格栅吸音墙、4 m 巨幕、两排观影软沙发、局域网双联游戏桌、桌球/桌游台与小冰吧；
  - **6–8 人宽敞私人卧室区**：取消 14 床拥挤营房，改为 **2 间宽敞双人主卧 + 4 间舒适单人房**（完整保留东侧双出口防火逃生前室）；
  - **干湿分离卫浴 + 小型暖木汗蒸桑拿 + 洗烘房**、**满墙藏书静谧书房**、**干净安心的家庭诊疗急救室**。
- **B3（`-18.6 m` · 立体自给农场与大型冷库酒窖）**：
  - 高密度水培/鱼菜种植区（补齐采收筐、园艺推车、操作台消除空旷感）、食品清洗真空打包间、大型低温冷库与恒温木酒架珍藏角、大容量不锈钢蓄水与净水站。
- **B4（`-22.8 m` · 能源与维生黑盒重器机房）**：
  - **静音柴油/燃气发电机组与地下油库**（替换旧微核堆）、大型储能电池阵与总配电室、三防新风过滤主机房、地热换热总站、深层集水泵房。外观厚重硬核，前台保持清晰黑盒状态。

## 3. 四阶段落地路线（先单间冲刺上限，再全楼铺开）

### 阶段 V3-1（`a6dcde4` + V3-1b 热修已完成）
- 根治材质拖动闪烁：分离共面饰面与所有 L1/L2/B1–B4 墙角重叠、启用 `polygonOffset`、8× 各向异性过滤与三线性 mipmap、法线高光抗走样（Specular AA）、全分辨率 `N8AO Medium`、`SMAA HIGH`、`2048` 级联阴影与动态相机裁剪面；
- 客梯（`L2–B4`）与大货梯（`L1–B4`，扩容至 **`2.6 m × 3.0 m × 2.65 m`**、门宽 `2.26 m`）全停靠口真可乘坐；
- 顶栏与 HUD 精简、0.65 s 房间直达转场、移除绿色胶囊小人。

### 阶段 V3-2（样板间试金石：卸包袱 + 原装 PBR GLB 管线 + 只做「B2 客厅与开放厨房」到极致）
1. **彻底删掉旧科研验证器包袱**：清除废弃的 10 人专家团、模拟隔离检修、红字热力学审计、6 大管网细分校验、蓝图模块合规试装代码与旧单测（历史已在 `v2.0-research-station` tag 留档）；将 `npm run perf` 精简为 ~10 个核心视角与乘梯交互段。
2. **B4 电源逻辑自洽化**：将后台状态模型从微核堆改为 6–8 人尺度 **静音柴油/燃气机组 + 油库 + 大储能电池 + 地热**，储备年限与仓库货架做轻量联动，使【堡垒状态】真实自然地运行在健康状态。
3. **升级原装 PBR `.glb` 资产加载管线**：支持 `GLTFLoader` + `DRACOLoader` 保留源模型自带 PBR 材质贴图（albedo/normal/roughness/metalness/ao），统一注入建筑剖切面、阴影投射接收与 8× 各向异性过滤，严守 CC0 许可并采用精简 1 行 `MANIFEST.md`。
4. **集中全部美术火力只打磨「B2 客厅与开放厨房（`b2_commons`）」这一间样板房**：
   - 严格对照 [ref-a-living-dining.jpg](references/b2-living/ref-a-living-dining.jpg) 与 [ref-b-open-kitchen.jpg](references/b2-living/ref-b-open-kitchen.jpg) 构图与气氛；
   - 压暗全局大白底光，落地暗调清水混凝土梁柱 + 暖橡木护墙板 + 暖火壁炉 + 2700K 吊灯光池 + 柜底灯带 + 挑空绿植中庭暖光；
   - 用真实 CC0 `.glb` 模型与高精木作/石材岛台替换方块沙发、茶几、8 座实木餐桌椅、厨房家电/锅具/咖啡机/杯盘书本与室内绿植；
   - 验收方式：**将 B2 客厅与厨房的浏览器实拍截图与两张参考图并排对比**——满意则沿此管线铺全楼，若觉得还差间接光则决定是否补 Blender 硬装烘焙或转 UE5。

### 阶段 V3-3（按 V3-2 样板标准铺开核心生活与囤货路线）
- 依次落地 **L1 实用车库（含真实越野车/工具墙/大货梯前室）与装备更衣间**、**L2 山景瞭望客厅与阳光花房**、**全楼中文门牌与电梯厅大总览导视**、**B2 私人影音游戏室与 6 间宽敞舒适卧室**、**B1 满载大仓库与东北武器工具库**。

### 阶段 V3-4（B3/B4 充实收口 + 外景远山云海升级 + 终验）
- 拉满 B3 农场/冷库酒窖/水库与 B4 柴油机组/电池/新风黑盒机房陈设密度；
- 升级远山大气层次与山谷云海，完成全 6 层乘梯试走验收。
