### M1（2026-11-26）工程底座与山体剖面

- 建立 Vite 6、React 19、严格 TypeScript、Tailwind 4、Three.js/R3F/Drei、Zustand、Lucide、Vitest 与 npm 锁文件。GitHub Actions 在 Node.js 22 上运行 `npm ci` 和统一验证入口。
- 录入 L2 至 B4 共 26 个房间。每个地下层的 122 格房间、13 格主走廊与 5 格竖井合计 140 格。面积、标高和剖面标注均读取蓝图或楼层定义。
- 建成程序化阶梯山体、沿坡车道、林地、地表科研站、6 m 岩层及四层地下骨架。楼板与缓冲层为竖井实际开孔。按工程规格第 1.1 和 4.2 节，西侧平硐设在 B1，连接洗消间。镀层钢架、玻璃、木饰面与程序化花岗岩纹理均在本地生成。
- 支持全山、半剖、12% 山体线框透视，三种相机预设，ALL 与任一楼层剥离、本层夹层显隐。构件保持原始标高，通过透明度过渡剥离。系统减弱动态偏好可以跳过过渡。
- `npm run verify` 通过。类型检查零错误，Vitest 共 3 个文件、26 项通过，Vite 生产构建成功。几何回归覆盖逐房坐标、逐格互斥与全覆盖、净高/夹层/叠层关系、实际楼板开孔、B1 平硐与山路开挖。
- Chrome 生产版检查覆盖 1440 × 900、1280 × 720、390 × 844 画幅，三种视图和取景、六层剥离、夹层、旋转缩放与减弱动态偏好。M1 Pro、1280 × 720、DPR 1 连续旋转采样约 60 FPS。已同步 README 的启动命令、视觉规范的剥离操作与技术架构的实现入口。
- M2 将写入房间设备实例，渲染入口沿用 `RoomInstance.bounds` 和 `coords.ts`。夹层开关目前显示检修空间与构架，后续 M3 管网可挂接在同一显隐条件下。
