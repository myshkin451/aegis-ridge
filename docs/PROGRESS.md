## M1.5b 返修二次签收（2026-11-27 · REVIEW）

本轮按 `npm run verify` → `npm run shots` → `npm run perf` 顺序通过。TypeScript 零错误，Vitest 的 6 个文件、53 项测试全部通过，Vite 生产构建成功。新增测试覆盖高速推近、屋顶、沿墙滑动、斜坡净距、飞行速度及 B2 移门轨道。

### 工程与画面改动

- 三级 CSM、N8AO、选择性 Bloom、SMAA 和 AgX 在六个视图间复用。材质以 uniform 选择表面细节，开场调用 `gl.compile`，再在小尺寸缓冲上预热实体、透明、裁切、深度、两种投影及后处理路径。第一帧完整光照经 GPU fence 确认后开放交互。剖切封口与漫游 MeshBVH 各构建一次。太阳阴影逐移动帧跟随，地下过渡使用室内补光。现场裁面为 0.5–15,000 m，步行为 0.12–350 m。
- 自动画质只在镜头移动时采样，剔除长任务与异常帧。每 90 个有效样本取中位数，连续 2 窗慢于 23 ms 或 8 窗快于 17.2 ms 才以 1/16 的步长调 DPR。静止时保留当前分辨率。
- `1–5` 直达五个主视图，`[` / `]` 切层。透视检视支持 WASD 水平飞行、Q 降 E 升、Shift 加速。现场镜头沿测区地表与 L1/L2 建筑外廓滑动。下潜先穿过打开的车库，再进货梯井。楼层落地从已剥开的上方进入。拖动、滚轮、按键可接管正在运动的镜头。
- 极寒光伏翼折至约 1° 并降低支架，百叶距离外墙轴线 0.49 m。B3 按旋转后的叶片外廓控制托盘余量。B2 移门沿房间侧独立轨道滑动，门框在廊面与门楣处收口，楼梯入口让出底横档。L1 四周新增 2.1 m 宽、约 2% 外坡的混凝土散水，外侧挡墙底逐段贴合高度场，楼板内保持 ±0.000。
- 远山背坡改用跨尺度连续噪声。林木在原有种植点变化树高、冠幅、偏冠与针叶色。三层云带以不同速度漂移，雷达罩与两台风机缓慢转动。减少动态效果时，镜头与普通滑门直接就位。操作和测量口径已同步到 README 与设计文档 02、03、05。
