## 当前激活目标

- **当前激活任务为 `M1.5b` 返修精修（`REWORK`，详见 `docs/04-codex-execution-roadmap.md` 中“阶段 M1.5b 返修精修”）**。M2 保持 `PENDING`，待返修跑通 `npm run verify`、`npm run shots` 与新增 `npm run perf`（切视图主线程冻结 `≤ 50 ms`、零新增着色器编译）并由用户二次签收后，再推进 M2。
- **M1.5b 首轮复测记录（2026-11-27，未签收原因）**：
  1. 真 GPU 实测各视角稳态 60 FPS，但切剖面/平面/漫游/X 光分别触发 32–42 次 `linkProgram` 着色器重编译与 200–300 ms 主线程冻结；静止期间自动画质在 1440/1080/2160 px 间跳档触发 220 ms 卡顿；0.16 s 节流导致旋转时阴影跳动。
  2. 轨道相机无地形/楼体防穿模（滚轮推近会钻入站房墙体），过渡直线插值不可打断，缺少 3D 视角 `WASD+Q/E` 自由飞行。
  3. 画面实锤瑕疵：极寒封锁光伏翼 `1.32 rad` 竖立、外挂百叶穿幕墙与木格栅；B3 样段水培叶片穿铝框；站房基座生插斜坡缺台基挡墙；远山背坡存在横向条纹。
- **关键历史纠偏备忘（M1 → v2.0）**：
  1. `vite.config.ts` 现同时收录 `tests/**/*.test.ts` 与 `src/**/*.test.ts`。本轮实际执行了放在 `src/geometry/` 下的楼梯测试。
  2. `coords.ts` 已从 `src/scene/utils/` 迁移至渲染无关的 `src/geometry/coords.ts`。
  3. 废弃 `14×10` 网格与 `2×2m` 过窄竖井，统一采用 `16×12` 网格、物理合规尺寸核心筒与全楼垂直干湿分区对齐。
  4. 废弃等高线纸板山、默认正交相机、Tailwind/Nord 暗色磨砂 SaaS UI；全面转向“山外实景 × 剖开图纸”双语域规格（`docs/02`, `docs/05`, `docs/06`）。

### M1.5a（2026-11-26）工程骨架、山体与外围设施 · 用户已签收

- 地下四层均为 16 × 12 格，每层 768 m²，合计 3,072 m²。逐格检查覆盖房间、物流走廊和五处井位。西北湿区和东北干区上下对齐。L2 温室向南集中种植和用水，北段保留干式观察区。标准层在现有井界内用四个短梯段折返，踏高、踏面和上下净空按生成的几何逐级核验。
- 固定种子生成 10 km、2.4 km、300 m 和 80 m 四级地形，另加密两处硐口。19 处外围设施可逐项定位。道路中心线、两侧路缘、索道吊斗净空与两座硐口均对实际渲染采用的地形网格做了回归检查。
